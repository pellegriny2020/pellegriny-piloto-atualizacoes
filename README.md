# Pellegriny Piloto

Aplicativo Android para analisar ofertas e acompanhar ganhos de quem trabalha de moto e carro.

Este espaço contém os APKs e informações de atualização. O código do projeto permanece privado.

## Baixar

Abra a [versão mais recente](https://github.com/pellegriny2020/pellegriny-piloto-atualizacoes/releases/latest) e baixe o arquivo APK.

Instale a atualização por cima da versão Teste existente para manter seus dados. O Android pede confirmação para instalar.
